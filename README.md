# creating_the_Easter_egg_pin
This is a description of creating a pin, which can be carried on bags, T-shirts. The design is inspired by The Easter egg.

# **Создание значка в виде Пасхального яйца**

## 1. Проектирование в Rhino

В Rhino необходимо создать 2D-модель пасхального яйца при помощи кривых. Размер около 30х40мм. Не следует создавать очень мелкие детали. Далее, необходимо сохранить файл в формате .dxf

## 2. Нарезание на лазерном станке

Мы будем создавать деревянную рамку для удобства во время сборки, а также само яйцо из двух листов акрила разного цвета, чтобы в дальнейшем взять основу от одного и добавить элементы от другого.
Нам понадобятся: акрил бордового цвета (толщина 3мм), акрил белого цвета (толщина 3мм), а также фанера (толщина 3мм/6мм).
В программе CorelDraw осуществляется задание параметров печати.

1) Создание рамки для сборки
Необходимо создать прямоугольную скругленную форму для деревянной формы (на рисунке 1 слева сверху). Можно вырезать дважды из фанеры 3мм, а потом склеить, или единожды из фанеры 6мм.
Параметры заданные: скорость 3 мощность 90.
   
3) Вырезание элементов яйца
Необходимо вырезать из бордового акрила внешний периметр яйца (на рисунке 1 справа снизу), он будет служить нижним слоев, а также само яйцо (на рисунке 1 слева снизу). Из белого акрила нужно вырезать само яйцо (на рисунке 1 слева снизу).
Параметры заданные: скорость 2,4 мощность 93.

## 3. Сборка

Для сборки нам понадобятся: клей и щипцы.
Нарезанные детали собираем в форме с помощью щипцов, скрепляя клеем.

## 4. Результат

Как итог, мы получаем
Результат получился не таким, каким его ожидали, потому что белый акрил смотрится прозрачным, теряется контраст между красным и белым, поэтому из оставшихся материалов было сделано второе яйцо. К тому же, некоторые детали склеились с деревянной формой, было затруднительно их отсоединить. Важная рекомендация: сделайте кромку по периметру фигуры для верхнего слоя, таким образом детали будут лучше держаться, сначала выложите в форме весь рисунок полностью и только потом смазывайте клеем основу яйца и приклеивайте к остальным элементам, по возможности уберите деревянную рамку, чтобы избежать склеивания.
